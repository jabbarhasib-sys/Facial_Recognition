# Facial Recognition System

This project implements a real-time facial recognition system using deep learning.

## Features
- Face detection using MTCNN
- Face recognition using FaceNet embeddings
- Real-time webcam recognition
- Cosine similarity-based verification

## Technologies Used
- Python
- OpenCV
- TensorFlow / Keras
- MTCNN
- FaceNet

## How It Works
1. Facial images are loaded from dataset folders
2. Face embeddings are extracted using FaceNet
3. Live camera input is compared with stored embeddings
4. Known faces are identified, others marked as Unknown

## How to Run
- Activate virtual environment
- Open `Facial_Recognition.ipynb`
- Run cells sequentially

## Output
- Real-time face recognition using webcam
